# Справочник по MTG

Веб-приложение для iPhone: четыре колоды из сета **The Hobbit (HOB)**. Каждая карта показана как оригинал, но весь текст на ней по-русски. Работает без интернета, ставится на экран «Домой».

Это неофициальный некоммерческий проект. Данные и картинки карт взяты из [Scryfall](https://scryfall.com), Magic: The Gathering — © Wizards of the Coast.

## Команды

Все команды запускаются в терминале VS Code из папки проекта.

| Команда | Что делает |
|---|---|
| `npm run fetch` | Скачивает данные и картинки из Scryfall (уже скачанное берётся из `data/raw`). |
| `npm run check` | Проверяет перевод: символы маны, числа, термины, буква ё. |
| `npm run build` | Собирает приложение: цвета плашек, размеры шрифта, `app.json`, `sw.js`. |
| `npm run serve` | Запускает сайт на компьютере: http://localhost:8080 |
| `node scripts/test-app.js` | Проверяет приложение в движке Safari и делает скриншоты в `screenshots/app`. |

## Как исправить перевод карты

1. Откройте `data/cards.json` и найдите карту по английскому названию.
2. Исправьте текст. Символы маны пишутся так: `{T}`, `{2}`, `{R}`, `{R/W}`. Новая строка — `\n`. Курсив для названий способностей вроде *Землепад*: `*Землепад*`.
3. Запустите `npm run check`, потом `npm run build`.
4. Опубликуйте изменения (см. ниже, «Как обновлять приложение»).

## Как поменять колоду

1. Исправьте `data/decks.json`.
2. Запустите `npm run fetch`. Новые карты скачаются, а скрипт покажет, что нашлось.
3. Добавьте перевод новых карт в `data/cards.json`.
4. Запустите `npm run check` и `npm run build`.

Для скачивания из Scryfall может понадобиться VPN: у некоторых провайдеров соединение со Scryfall обрывается.

## Как обновлять приложение

1. Внесите правки (например, в `data/cards.json`).
2. В терминале VS Code выполните по очереди:
   ```
   npm run check
   npm run build
   git add -A
   git commit -m "Коротко, что изменили"
   git push
   ```
3. Через 1–2 минуты сайт обновится. Ход публикации видно на вкладке **Actions** репозитория: зелёная галочка — готово.
4. На телефоне: откройте приложение с интернетом, подождите несколько секунд, закройте его (смахните вверх) и откройте снова — появится новая версия. При каждой сборке меняется версия кэша в `site/sw.js`, поэтому старые файлы на телефоне заменятся новыми.
