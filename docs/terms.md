# Словарь терминов для перевода

Этот словарь — основа перевода всех 103 карт. Каждый термин проверен по картам, которые официально печатались на русском языке (поиск в Scryfall с `lang:ru`, поля `printed_text` и `printed_type_line`). В графе «Источник» указано: русское название карты → английское название, код сета и год.

Если русских карт с термином нет (новые механики «Хоббита»), стоит пометка **«наш перевод»**.

Сырые данные проверки лежат в `data/ru-term-evidence.json` (по 3 русские карты на каждый термин).

---

## 0. Решения, которые нужно подтвердить

1. **Буква ё.** На официальных русских картах её не печатают («Полет», «зеленый», «повернутый»). Для 12-летнего читателя ё помогает читать правильно. **Предлагаю писать ё везде** («Полёт», «зелёный»). Сами термины от этого не меняются.
2. **Dwarf → Гном.** Это совпадает с официальным переводом: на русских картах 2022 года Dwarf тоже «Гном» (Серьезный Новобранец → Solemn Recruit, CLB 2022: «Существо — Гном Воин»).
3. **Storied, Recruit, Amass Goblins, «first main phase»** — новых формулировок нет на русских картах. Мои варианты ниже помечены «наш перевод».

- **Сказание** (Если под вашим контролем есть три или больше артефакта, легендарных перманента и/или Саги, вы получаете вечное сказание до конца партии.)

- **используйте Скопище Гоблинов 1.** (Положите один жетон +1/+1 на Армию под вашим контролем. Она также является Гоблином. Если под вашим контролем нет Армии, то сначала создайте одну фишку существа 0/0 чёрная Армия Гоблинов.)
